# Protest Style: сайт и Telegram-магазин

Один сервер обслуживает сразу три вещи:
- **сайт** на своём домене: каталог, страницы товаров, корзина, версия для компьютера;
- **мини-приложение** в Telegram: тот же магазин по кнопке «Магазин» в боте;
- **бота**, который переносит посты канала на сайт и присылает заказы.

Товары, фото и заказы лежат в хранилище S3 на Timeweb, на серверах в России.

## Как это работает

- Друг выкладывает пост в канал. Бот скачивает фото и видео, вынимает из подписи название, цену, размеры и мерки, и товар появляется на сайте. Боту, который подключён к заказам, приходит отчёт со ссылкой на товар.
- Друг правит пост, например меняет цену. Товар на сайте обновляется сам.
- Друг дописывает в пост `#продано` или отдельную строку «Продано». Товар скрывается с сайта.
- Посты без цены (анонсы, отзывы) на сайт не попадают.
- Покупательница оформляет заказ. Он сохраняется в админке и приходит в Telegram с кнопками статусов «Подтверждён / Оплачен / Отправлен / Отменён».

**Админка.** Чтобы войти, нужно 5 раз быстро нажать на логотип PS и ввести пароль. В админке можно:
- добавлять и править товары;
- менять обложку;
- смотреть заказы и выгружать их для Excel;
- перенести товары из старой Google Таблицы.

## Запуск на Timeweb Cloud

### 1. Хранилище S3
1. Откройте **Хранилище S3 → Создать**. Создайте два бакета:
   - `protest-style-media`, тип **публичный**. Здесь будут фото и видео.
   - `protest-style-data`, тип **приватный**. Здесь будут товары и заказы.
2. В бакете откройте вкладку с ключами доступа. Скопируйте **Access Key** и **Secret Key**.

### 2. Бот
Если бот уже есть, используйте его токен от @BotFather. Если нет: `/newbot` в @BotFather, затем скопируйте токен.

### 3. App Platform
1. Откройте **App Platform → Создать → Backend → Dockerfile**.
2. Подключите GitHub-репозиторий, ветка `main`.
3. Выберите самую маленькую конфигурацию.
4. В **Переменные окружения** впишите значения из `.env.example`:
   - `SITE_URL`: адрес сайта. Пока нет своего домена, это технический адрес, который даст Timeweb.
   - `ADMIN_PASSWORD`: новый длинный пароль админки.
   - `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET=protest-style-media`, `S3_DATA_BUCKET=protest-style-data`.
   - `TG_BOT_TOKEN`, а если нужно, `TG_CHANNEL=@protest_style`.
5. Запустите деплой. Проверить, что всё работает, можно по адресу `SITE_URL/api/health`. Там должно быть `"storage":{"mode":"s3","ok":true}` и `"bot":true`.

### 4. Свой домен
Купите домен, привяжите его в настройках приложения и поменяйте `SITE_URL` на новый адрес. После этого в админке нажмите **Заказы → Подключить бота заново**.

### 5. Канал и уведомления
1. Добавьте бота в канал администратором. Хватит права «Публикация сообщений», читать посты оно тоже разрешает.
2. Напишите боту в личку: `/admin ваш-пароль`. Бот удалит это сообщение и будет присылать заказы и отчёты о постах. Отключить уведомления можно командой `/stop`.

Кнопку «Магазин» в меню бота сервер настраивает сам.

### 6. Перенос старых товаров
В админке откройте **Заказы → Перенос со старой Google Таблицы**, вставьте ссылку на скрипт (заканчивается на `/exec`) и нажмите «Перенести».

## ИИ для разбора постов (по желанию)
Без ИИ бот разбирает посты по правилам. Он находит:
- цену, например «Цена 23.000 р»;
- размеры с мерками, например «s талия 64, бедра 98»;
- название в строке перед размерами.

С ИИ разбор точнее, и названия с описаниями переводятся на английский, украинский, турецкий и китайский. Подходит любой OpenAI-совместимый API, например ИИ-сервисы Timeweb, YandexGPT или DeepSeek. Нужно заполнить переменные `AI_BASE_URL`, `AI_API_KEY` и `AI_MODEL`.

## Для разработчика
- Нужен Node.js 20+ и ffmpeg. Внешних npm-пакетов нет.
- Запуск: `ADMIN_PASSWORD=test npm start`. Без ключей S3 данные пишутся в папку `.local-storage`.
- Тесты при запущенном сервере: `node test/run.js http://localhost:3000 test` (API) и `node test/bot.js` (бот с подменённым Telegram).
